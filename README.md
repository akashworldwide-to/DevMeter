🚀 DevMeter

Measure Your Developer Journey.

GitHub developer analytics made simple. 📊

Enter a GitHub username and get a clean overview of:

👤 Profile stats
⭐ Stars & forks
📦 Repositories
💻 Top languages
📈 Activity
🏆 Developer score
🎨 Shareable profile card

🛠️ Built With

React • TypeScript • Tailwind CSS • GitHub API • Vite

🚀 Run Locally

git clone https://github.com/akashworldwide-to/devmeter.git
cd devmeter
npm install
npm run dev
